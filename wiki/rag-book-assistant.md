## Overview

The RAG Book Assistant is an intelligent document query system that allows users to ask questions about PDF documents and receive accurate, context-aware answers. It uses Retrieval-Augmented Generation (RAG) technology to combine information retrieval with text generation.

(source: Utkarsh Sharma.md)

## Technical Stack

- **Framework**: Streamlit (web application)
- **LLM Framework**: LangChain
- **AI Model**: Mistral AI
- **Vector Database**: Chroma DB
- **Language**: Python

## Features

### Document Processing
- Loads and processes PDF documents
- Chunks documents into manageable segments
- Creates embeddings for semantic search

### Retrieval-Augmented Generation
- Uses vector embeddings to find relevant document sections
- Retrieves contextually relevant information
- Generates answers based on retrieved content
- Ensures responses are grounded in the source documents

### User Interface
- Streamlit-based web interface
- Easy-to-use question input
- Displays answers with source references
- Interactive and responsive design

## Benefits

- **Accuracy**: Answers are based on actual document content
- **Efficiency**: Eliminates manual document search
- **Context Awareness**: Understands context from the documents
- **Scalability**: Can handle multiple documents and large knowledge bases
