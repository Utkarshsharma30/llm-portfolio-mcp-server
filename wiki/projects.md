## Project List

### 1. PDF Invoice Data Extraction & Automation
- **Tech Stack**: Python, Tesseract, PyPDF2, OCR, OpenAI API
- **Description**: Automated PDF processing pipeline that extracts and structures invoice data from both text-based and scanned PDFs. Implements OCR fallback (pytesseract, pdf2image) and regex-based parsing. Transforms unstructured data to structured JSON/CSV, eliminating manual data entry.
- **Skills Demonstrated**: Python, OCR, regex, automation, API integration

### 2. RAG Book Assistant
- **Tech Stack**: Streamlit, LangChain, Mistral AI, Chroma DB
- **Description**: Retrieval-Augmented Generation system enabling intelligent Q&A over PDF documents. Uses semantic search via embeddings and a vector database (Chroma). Context-aware prompt pipeline ensures accurate, document-grounded responses.
- **Skills Demonstrated**: RAG, LLMs, vector databases, prompt engineering, Streamlit

### 3. Traffic Flow Prediction
- **Tech Stack**: Python, Random Forest, Scikit-learn, Pandas
- **Description**: Analyzed historical traffic data to identify congestion patterns and predict traffic situations using a Random Forest Classifier. Full data preprocessing, feature engineering, and missing value handling.
- **Skills Demonstrated**: Machine learning, data preprocessing, feature engineering, classification

### 4. Cafe and University Management Systems
- **Tech Stack**: JAVA, MySQL, NetBeans, MySQL Workbench
- **Description**: Desktop applications for café orders, billing, inventory management, and student records/course enrollment. Implemented MySQL CRUD operations and OOP design.
- **Skills Demonstrated**: Java, MySQL, OOP, database design, desktop applications

### 5. Ola Data Analysis
- **Tech Stack**: Power BI, MySQL, Excel, Data Analysis
- **Description**: Interactive Power BI dashboard analyzing 100,000+ data points including booking trends and revenue insights. Delivered actionable insights on ride frequency, cancellations, and driver ratings.
- **Skills Demonstrated**: Data visualization, BI tools, data analysis, reporting

### 6. Fun Chat Bot (Jassi Chatbot)
- **Tech Stack**: Python, Streamlit, LangChain, Mistral AI
- **Description**: Interactive chatbot with conversation memory and fun personality named Jassi. Built using Streamlit, LangChain, and Mistral AI.
- **Skills Demonstrated**: Chatbot development, LLMs, conversation management, web apps

### 7. Markdown Personal Wiki & Knowledge Graph MCP Server
- **Tech Stack**: Node.js, PostgreSQL, Model Context Protocol (MCP), Render, Claude Connector, Markdown
- **Description**: Personal wiki with pages, tags, and bidirectional knowledge graph following the Karpathy pattern (raw sources → structured wiki → knowledge graph → query flow). Indexed into PostgreSQL with a Node.js MCP server exposing search, page lookup, and link-graph tools, deployed publicly on Render and connected to Claude as a custom connector.
- **Skills Demonstrated**: MCP server development, knowledge graph modeling, PostgreSQL indexing, cloud deployment (Render), LLM custom connectors
