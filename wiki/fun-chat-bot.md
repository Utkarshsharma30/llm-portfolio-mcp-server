# Fun Chat Bot (Jassi Chatbot)

**Summary**: Interactive chatbot built using Streamlit, LangChain, and Mistral AI that maintains conversation memory and responds with a fun personality named Jassi.

**Sources**:
- raw/Utkarsh Sharma.md

**Last updated**: 2026-08-26

## Overview

The Fun Chat Bot, also known as Jassi Chatbot, is a conversational AI application that provides an engaging and interactive user experience. It uses modern AI frameworks to create a chatbot with personality and memory capabilities.

(source: Utkarsh Sharma.md)

## Technical Stack

- **Language**: Python
- **Framework**: Streamlit (web application)
- **LLM Framework**: LangChain
- **AI Model**: Mistral AI

## Features

### Conversation Management
- Maintains conversation history and context
- Remembers previous interactions
- Provides coherent, context-aware responses

### Personality
- Fun, engaging personality named Jassi
- Personalized responses
- Conversational tone

### Web Interface
- Streamlit-based web application
- Simple and intuitive user interface
- Real-time conversation display

## Benefits

- **User Engagement**: Fun personality keeps users engaged
- **Memory**: Maintains context across conversation turns
- **Accessibility**: Easy to use through web browser
- **Extensibility**: Can be enhanced with additional features

## Skills Demonstrated

- Chatbot development
- Large Language Models (LLMs)
- Conversation memory management
