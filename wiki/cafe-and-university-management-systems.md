# Cafe and University Management Systems

**Summary**: Desktop applications for café orders, billing, inventory management, and student records/course enrollment using Java, MySQL, and object-oriented programming.

**Last updated**: 2026-08-26

## Overview

This project involves the development of two separate but related desktop applications: one for managing a café's operations and another for university student records and course enrollment. Both systems use Java, MySQL, and object-oriented programming principles.

(source: Utkarsh Sharma.md)

## Technical Stack

- **Language**: Java
- **Database**: MySQL
- **IDE**: NetBeans
- **Database Tool**: MySQL Workbench
- **Paradigm**: Object-Oriented Programming (OOP)

## Cafe Management System

### Features
- Order management
- Billing system
- Inventory tracking
- Customer records

### Capabilities
- Create, Read, Update, Delete (CRUD) operations for café data
- Efficient data handling using MySQL
- User-friendly interface for staff

## University Management System

### Features
- Student records management
- Course enrollment
- Faculty information
- Academic records

### Capabilities
- CRUD operations for student and course data
- Relationship management between students and courses
- Academic record tracking

## Architecture

- **Modular Design**: OOP principles for clean, maintainable code
- **Database Integration**: MySQL for data persistence
- **User Interface**: Desktop GUI for easy interaction
- **Separation of Concerns**: Clear division between data, business logic, and presentation
