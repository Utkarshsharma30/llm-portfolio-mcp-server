## Projects

### 1. PDF Invoice Data Extraction & Automation
- **Tech Stack**: Python, Tesseract, PyPDF2, OCR, OpenAI API
- **Description**: Automated PDF processing pipeline that extracts and structures invoice data from both text-based and scanned PDFs. Implements OCR fallback (pytesseract, pdf2image) and regex-based parsing. Transforms unstructured data to structured JSON/CSV, eliminating manual data entry.

### 2. RAG Book Assistant
- **Tech Stack**: Streamlit, LangChain, Mistral AI, Chroma DB
- **Description**: Retrieval-Augmented Generation system enabling intelligent Q&A over PDF documents. Uses semantic search via embeddings and a vector database (Chroma). Context-aware prompt pipeline ensures accurate, document-grounded responses and eliminates manual document search.

### 3. Traffic Flow Prediction
- **Tech Stack**: Python, Random Forest, Scikit-learn, Pandas
- **Description**: Analyzed historical traffic data (vehicle counts, time, day) to identify congestion patterns and predict traffic situations using a Random Forest Classifier. Performed full data preprocessing, feature engineering (datetime conversion, encoding), and handled missing values to improve accuracy.

### 4. Cafe and University Management Systems
- **Tech Stack**: JAVA, MySQL, NetBeans, MySQL Workbench
- **Description**: Developed a desktop application for café orders, billing, and inventory management. Implemented MySQL CRUD operations for efficient data handling. Created a system for managing student records and course enrolment. Used object-oriented programming for modular design.

### 5. Ola Data Analysis
- **Tech Stack**: Power BI, MySQL, Excel, Data Analysis
- **Description**: Developed an interactive Power BI dashboard to analyze and visualize over 100,000+ data points, including booking trends and revenue insights. Delivered actionable insights on ride frequency, cancellations, and driver ratings for decision-making scenarios.

### 6. Fun Chat Bot (Jassi Chatbot)
- **Tech Stack**: Python, Streamlit, LangChain, Mistral AI
- **Description**: A simple and interactive chatbot built using Streamlit, LangChain, and Mistral AI. The chatbot maintains conversation memory and responds with a fun personality named Jassi.

### 7. Markdown Personal Wiki & Knowledge Graph MCP Server
- **Tech Stack**: Node.js, PostgreSQL, Model Context Protocol (MCP), Render, Claude Connector, Markdown
- **Description**: Personal wiki with pages, tags, and bidirectional knowledge graph following the Karpathy pattern (raw sources → structured wiki → knowledge graph → query flow). Indexed into PostgreSQL with a Node.js MCP server exposing search, page lookup, and link-graph tools, deployed publicly on Render and connected to Claude as a custom connector.
